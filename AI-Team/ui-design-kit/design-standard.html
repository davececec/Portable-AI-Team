S
Light SaaS Design Language

Shopeers 电商数据分析设计标准

这是一套以清晰层级、柔和阴影和高密度数据表达为核心的 SaaS 界面规范。适合用作分析后台、订单管理、客户增长和商业报表类页面，也可直接复用到其他 Web 产品中。

Browse components

Clarity first

用留白、层级和颜色区分信息优先级，避免装饰干扰数据。

Human SaaS

浅色中性底、低饱和色块和小圆角让界面显得可信且轻盈。

Data density

表格、图表和 KPI 都保持紧凑，但每个区块仍然有呼吸感。

Quiet motion

只使用 0.2 秒级别的轻量过渡，不做弹跳、发光或复杂特效。

Layout

页面结构

整体采用「固定侧边导航 + 吸顶工具栏 + 滚动内容区」的结构。主内容不超过 1440px，卡片之间统一 16px 间距。

侧边栏宽度Desktop 244px，中屏收窄为 icon rail，移动端改为抽屉。
顶栏高度64px，sticky，带 1px 底部边框。
内容区左右内边距 24px，最大宽度 1440px。
模块间距卡片间 16px，区块标题下 20-24px。

Responsive

响应式规则

大屏优先保持数据密度，中屏折叠导航，移动端不硬塞桌面表格，而是按内容优先级堆叠。

BreakpointLayoutRecommended behavior
≥1280px4 columns完整侧边栏，KPI 四列，主图表占 2/3 宽度。
1024-1279px2-3 columns侧边栏收成 icon rail，KPI 仍可保持 2-4 列。
768-1023px2 columns侧边栏改抽屉，卡片 2 列，表格可横向滚动。
<768px1 columnKPI 堆叠，筛选器收起，操作按钮变成整行。
