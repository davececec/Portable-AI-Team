# 完成标准

记录跨任务稳定适用的验收与交付要求。

预算：每条不超过 300 字；最多 40 条且不超过 8,000 字符。

- 2026-09-20 Android 任务验收线：① 代码层 `:app:assembleDebug` 必须 BUILD SUCCESSFUL，APK 产物更新；② 改造类任务须做差异自查，确认核心机制（加密/锁定/弹窗/数据迁移等）未被误伤；③ 视觉层无设备时显式标注"未验证"，提供 adb 装机或建模拟器两条后续路径；④ 返工最多 2 轮，超限上报而非反复试错。
- 2026-09-22 模块化系统复刻验收线：每个模块须同时具备数据表/迁移、字段字典、API 契约、前端页面、加载/空数据/错误状态、单元或接口测试、真实浏览器检查；通过后才进入下一模块。UI 在 1440×900、1024×768、768×900、390×844 检查无横向页面滚动、无遮挡、图表非空且状态语义一致。
- 2026-09-22 Web 响应式完成线：桌面、平板、手机必须同阶段交付；禁止依赖整体页面缩放或固定桌面侧栏。手机应使用抽屉/底部导航，宽表转换为摘要卡或可控局部滚动，筛选与 AI 使用移动端抽屉；至少验证 1440、1024、768、390、360px 宽度及触控可操作性。
- 2026-09-22 新系统目录验收线：业务开发前必须完成目录方案、模块职责、依赖方向、配置策略和生成物隔离；仓库不得混入日志、临时探针、浏览器缓存、虚拟环境、node_modules、打包输出、真实密钥。每类能力只保留一个明确主入口，废弃入口和兼容脚本须有迁移说明后删除。
