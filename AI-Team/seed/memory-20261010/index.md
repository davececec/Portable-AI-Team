# 记忆索引

先读本索引，再按任务选择 1-3 个文件；禁止默认读取全部记忆。

| 分类 | 文件 | 何时读取 |
| --- | --- | --- |
| 用户偏好 | `user-preferences.md` | 沟通、输出或交互偏好相关 |
| 技术栈 | `tech-stack.md` | 选型、构建、兼容性相关 |
| 完成标准 | `completion-criteria.md` | 定义验收或交付边界 |
| 反馈模式 | `feedback-patterns.md` | 处理反复出现的用户反馈 |
| 缺陷模式 | `defect-patterns.md` | 调试或回归风险相关 |
| 有效方案 | `effective-solutions.md` | 可复用实现或排障方法相关 |
| 技术决策 | `technical-decisions.md` | 架构、依赖或取舍相关 |
| 项目历史 | `project-history.md` | 修改既有项目或恢复上下文 |

**团队资料（非记忆，按需直读）**：涉及界面开发/美化时，除记忆外必须读 `../UI/UI-DESIGN-STANDARD.md`（三风格设计规范，含参考实现 demo）；这是团队自带的稳定资料，不随项目带走。

每条不超过 300 字；每个分类文件最多 40 条且不超过 8,000 字符。达到任一上限时合并重复项并压缩最旧内容，保留仍有效的结论。仅记录新出现且稳定的经验，不为记忆更新单独调用模型。

项目完成或准备带走团队时，AgentA 将项目摘要压缩到 `project-history.md`，并按需更新其他七类。只带走稳定、可复用的结论；禁止记录业务源码、密钥、原始日志、构建产物或项目依赖。
